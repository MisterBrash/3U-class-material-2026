### The Lesson: 👂 Event Listeners

When a user interacts with a webpage (click, mouse move, key press, etc) this creates _events_. You can find [the entire list of events online](https://www.w3schools.com/jsref/dom_obj_event.asp).

In order to have the event trigger some code (clicking a button, using a keyboard, hovering over an image), we tell the HTML document to **listen** for that specific **event**. The function is called **an event listener**.

### There are two ways to listen for an event:

**1. In HTML (the easy method):**
```HTML
Use the "on" event trigger:
<img id="options" src="./images/options.png" onclick="load_options()">
```

This approach _assumes_ that the JavaScript is ready and loaded properly. It causes us to put JS code in two places - the document _and_ the JS file. Similar to how we separate out the CSS, we would rather _not_ use the above method.

**2. In JavaScript (the preferred method):**
```JS
// Setup an Event Listener
document.getElementById("options").addEventListener("click", load_options);
```

#### Example 1: Roll a D6
[🔝 Back Up](#43---event-listeners)

The `index` file has a _button_ that says "Roll a D6". We will code a function to roll a 6-sided die and place the results in the `<span>` called "die_roll".
```JS
function rolld6() {
  // Roll the die
  $("die_span").textContent = randInt(1, 6);

  // Make sure the <div> is visible
  $("die_div").hidden = false;
}
```

That function will only work when we call it. Let's connect it to the button by adding an _event listener_ on line 12 to make the button clickable:
```JS
$("d6Button").addEventListener("click", rolld6);
```

Now go click the button a couple times!

#### Example 2: Getting Input
[🔝 Back Up](#43---event-listeners)

Our page also contains an input box:
```HTML
  <input id="user_input" type="text" ... >
```

It is asking for the user's name. Let's say hello to them when they click the "Enter" button.

**Step 1** - Create the function
```JS
function sayHello() {
    // Get what the user entered
    let name = $("user_input").value;

    // Say hello
    $("greeting").textContent = `Hello ${name}!`;
}
```

**Step 2** - Add the Event Listener on the Enter button (typically all listeners are placed at the _**top**_ of your code file)
```JS
$("enter").addEventListener("click", say_hello);
```

Test it out.

### Part 4 - The MouseEnter and MouseLeave Events

There are so many awesome [mouse events](https://www.w3schools.com/jsref/obj_mouseevent.asp) we can use! We've already seen the [click event](https://www.w3schools.com/jsref/event_onclick.asp) but now let's talk about moving our mouse into and out of an element.
