### The Lesson: The Event Object

Every function called by an event listener receives an argument called [The Event Object](https://www.w3schools.com/jsref/obj_events.asp). The properties of the Event Object depend on what kind of event was called ([Mouse](https://www.w3schools.com/jsref/obj_mouseevent.asp), [Keyboard](https://www.w3schools.com/jsref/obj_keyboardevent.asp), etc...).

Let's take the [keydown](https://www.w3schools.com/jsref/event_onkeydown.asp) event as an example. If you recall we have an input textbox on our page:
```HTML
<input id="user_input" ...
```

And we wrote a quick function `sayHello()` that says hello to the name put in the box.

Currently the user has to click the "enter" button to make it happen. Let's also make it happen when the user hits the `Enter` key on their keyboard.

```JS
$("user_input").addEventListener("keydown", checkKey);

function checkKey(event) {
  if (event.key == "Enter") {
    sayHello();
  }
}
```

> Notice the `event` parameter in the function. In the background the listener receives this argument full of [interesting properties and information](https://www.w3schools.com/Jsref/dom_obj_event_prop.asp).

### Part 1 - Tracking the Mouse

The [Mouse Event](https://www.w3schools.com/jsref/obj_mouseevent.asp) tracks _all sorts_ of data about the cursor, clicks, scrolling... Let's track its location:
- Add a `<div>` somewhere on your page to update while the mouse moves. Give it an id like "mouseLocation".
- Create the function `tracking(event)` which updates the `<div>` by modifying the `.textContent` with the `event.clientX` and `event.clientY`, compared to the `event.screenX` and `event.screenY`
  - Something like this:  `Client: x, y | Screen: x, y` or similar
- Add an event listener to the _document_ to track the mouse: `document.addEventListener("mousemove", tracking)`

### Part 2 - Three Buttons, One Function

Sometimes you want to call the same function with several inputs and do something different depending one which input was used. **Let's test that**.

- Add three buttons to the page Button 1, Button 2, Button 3 and give them appropriate IDs like "btn1", "btn2", "btn3"
- Create the function `whichButton(event)`
- Add a `click` event listener to all three buttons and have them all call the `whichButton` function
- In the `whichButton(event)` function, use the `event.target.id` to figure out which button called the function and change the background colour of the page to a certain colour based on the button that was clicked.  
**Example:** `document.body.style.backgroundColor = "rgb(175, 150, 0)";`

> **Extension**: Add some code that reveals a secret or does something interesting if the three buttons are clicked in a particular order! (**hint**: you'll need a global variable to help keep track of the clicks)
