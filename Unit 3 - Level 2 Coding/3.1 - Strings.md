### Strings Are _Primitive_ - or Are They?

`Primitive` variables are **simple**: _a number_, _a boolean_, _a single character_

`Objects` have functions (methods) and are more **complex**: `Math`, `console`, `document`

A `string` in JavaScript is **_both_**. 

```JS
let myName = "Mr. Squirrel"
```

That declaration creates a `primitive` variable which holds _multiple_ characters "strung together" like Christmas lights. They can be temporarily "wrapped" or "converted" into a more complex `Object` if the coder needs something from it.  

<img src=".assets/string_of_lights.png" width="400px">

**Example:** The word `hello` is a string made of the chars `'h' 'e' 'l' 'l' 'o'` where `h` is in position `0` and `o` is in position `4`.

Each character is a symbol (drawing) tracked by a number in the computer's memory. The computer looks-up the symbol, based on that number.
- [ASCII Characters](https://ss64.com/ascii.html)
- [Unicode Characters](https://en.wikipedia.org/wiki/List_of_Unicode_characters)

<br>

**Recall:** We can "build" a `String` using the _concatonate_ feature - the `+` operator:
```JS
let my_output = "";
let t = "third";

my_output += "First" + " " + "second" + t;

return my_output;    // returns "First secondthird"
```

There is also a `.concat()` function:
```JS
"Hello".concat(" ", "World!")

// Similar:
let h = "Hello"
let w = "World!"

h.concat(" ", w)
```

## Properties & Methods

###### [⬆ Top](#31---strings)

A _property_ is a fact about an object.
- For example: _Strings_ have the [`.length`](https://www.w3schools.com/jsref/jsref_length_string.asp) property
  ```JS
  let myString = "Hello World!";
  console.log(myString.length);   // Prints 12 to the screen
  ```

- `.length` provides the _number of characters in the string_ - **not** the last character (zero indexed)
- `[ ]`, [`.charAt()`](https://www.w3schools.com/jsref/jsref_charat.asp), [`.at()`](https://www.w3schools.com/jsref/jsref_string_at.asp)
  - Each character in a string has a **position** or **index**.
  - To get a character in the string we can use the shortcut `[#]` where "#" is an address or index of the character.
  - The left-most, or first, is at **position zero** `myString[0]` or `"hello"[0]`.
    - Ex:  `"Hello"[1]` is the character "e" and `"Mr. Squirrel"[3]` is the space character " "

- It is very important to remember that "a" and "A" are considered *different*. `"Hello" != "hello"`
- **Strings are _immutable_**: you cannot change a character in a string yourself:
    ```JS
    let myName = "Ms. Brash"
    myName[1] = "r"     // Does NOTHING
    ```

A _method_ - is a function that an object can _perform_ to manipulate data or give a result.

- Strings have [lots of useful methods](https://www.w3schools.com/js/js_string_methods.asp) but the ones we might focus on are:  
  - [`.substring()`](https://www.w3schools.com/jsref/jsref_substring.asp) and [`.slice()`](https://www.w3schools.com/jsref/jsref_slice_string.asp)
  - [`.toUpperCase()`](https://www.w3schools.com/jsref/jsref_touppercase.asp) and [`.toLowerCase()`](https://www.w3schools.com/jsref/jsref_tolowercase.asp)  
  - [`.charCodeAt()`](https://www.w3schools.com/jsref/jsref_charcodeat.asp)  
  - [`.indexOf()`](https://www.w3schools.com/jsref/jsref_indexof.asp)
... and _many more_, with [awesome examples at w3schools](https://www.w3schools.com/js/js_string_methods.asp)!

- Another very useful tool is the ability to get a _character_ based on its [numeric code](https://ss64.com/ascii.html). For that we use `String.fromCharCode()` and give the Unicode number.
  ```JS
  let my_char = String.fromCharCode(64);   // the '@' character
  console.log(String.fromCharCode(122));   // 'z'
  ```

## Examples

###### [⬆ Top](#31---strings)

**Don't forget!** To get a single character from the string we can use `myVar.charAt(index)` **or the easier shortcut of `myVar[index]`** or `myVar.at(index)` which allows for _negative indices_.

```JS
let longText = "Supercalifragilisticexpialidocious!";

longText.length                 // 35

longText[0]                     // S

longText.charAt(5)              // c

longText[longText.length]       // undefined

longText[longText.length - 1]   // !

longText.at(-1)                 // !
```

We can also _**build**_ a String, if necessary:
```js
let userName = prompt("What is your first name?").concat(" ", prompt("what is your last name?"))
```

Convert to UPPER or lower case:
```JS
let quiet = "hello"
let loud = quiet.toUpperCase()
```

Get a substring:
```JS
let myVar = "Hello World!"
let spaceLocation = myVar.indexOf(" ")
let firstWord = myVar.substring(0, spaceLocation)
```

1. Create the function `shout(text)` that takes a string, converts it to all UPPERCASE, and adds three exclamation marks to the end.  

    **Example:** `shout("hello")` returns `"HELLO!!!"`.

2. Create the function `getInitials(firstName, lastName)` that takes two strings and returns the first letter of each, capitalized, with a period in between.  

    **Example:** `getInitials("clark", "kent")` returns `"C.K."`.

3. Create the function `maskPhone(number)` that takes a 10-digit phone number (as a string) and returns just the last 4 digits with "xxx-xxx-" at the start.

    **Example:** `maskPhone("6135551234")` returns `"xxx-xxx-1234"`.  
    **Hint:** `.slice()` or `.substring()`.

4. Create the function `makeUsername(email)` that takes a school email (e.g., john.doe@stu.ocsb.ca) and returns a username consisting of the first 3 letters of the email plus the length of the entire email string.

    **Example:** `makeUsername("smith.j@school.ca")` returns `"smi17"`.
